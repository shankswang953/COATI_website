# Palate

The palate tutorial evaluates strict leave-one-stage-out reconstruction with the
prepared paired RNA and ATAC embeddings.

  support recall, Sinkhorn-based $W_2$ and composition similarity independently
  in RNA PCA40 and ATAC LSI15, then compare observed and predicted E13.5/E14.0
  distributions in shared global UMAPs.
